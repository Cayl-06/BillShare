# BillShare

BillShare is a 100% Kotlin-powered application designed to simplify the process of splitting bills, expenses, and group costs. Whether you're sharing rent with roommates, tracking vacation expenses, or managing group purchases, BillShare provides an intuitive interface and powerful features to ensure everyone pays their fair share.

## Features

- **Easy Bill Splitting:** Quickly divide expenses among any number of participants, with options for equal or custom splits.
- **Expense Tracking:** Log and categorize every shared cost for clear, organized tracking.
- **Settlement Suggestions:** Instantly see who owes whom and recommended ways to settle up.
- **Group Management:** Create and manage groups (households, trips, events) with dedicated expense histories.
- **Kotlin-First Design:** Leveraging modern Kotlin architecture for robust, maintainable, and efficient code.
- **User-Friendly UI:** Clean, accessible, and mobile-friendly interface to keep managing expenses simple.
- **Secure Storage:** Privacy-minded data handling—your billing information stays yours.
- *(Optional)* **Cloud Sync:** Sync data across devices (if implemented).

## Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Cayl-06/BillShare.git
   ```

2. **Open in Android Studio:**  
   Open the folder and build using Android Studio (ensure you have the latest stable version).

3. **Run the app:**  
   Deploy on an emulator or your Android device.

## Usage

1. Create or join a group.
2. Add your expenses as they occur.
3. Assign participants and amounts (split equally or manually).
4. Track balances and expenses over time.
5. Use settlement suggestions to resolve outstanding IOUs.
